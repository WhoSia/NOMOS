# P2-P36 — Cortez supplies a real recipient readback

The court recounts a false OFAC identity match in the auto dealer's credit report, although the consumer-facing file did not show the alert. The dealership investigated and delayed the sale, which took place later that day. These events precede the subsequent dispute response. [Cortez v. Trans Union, 617 F.3d 688, slip op. pp. 8–13](https://www.govinfo.gov/content/pkg/USCOURTS-ca3-08-02466/pdf/USCOURTS-ca3-08-02466-0.pdf#page=8).

Trans Union's May 10, 2005 response stated that the disputed information did not currently appear. The June 3 dealer report still displayed an OFAC name-screen alert while replacing the earlier HAWK alert language. The second inquiry was made to verify the report's contents. The opinion supports a dated discrepancy between a response and the recipient copy. The later check does not document a second credit decision or when the upstream field was last changed. [Slip op. pp. 17–19, citing J.A. 545–546](https://www.govinfo.gov/content/pkg/USCOURTS-ca3-08-02466/pdf/USCOURTS-ca3-08-02466-0.pdf#page=17).

Use Cortez to test whether a review independently asks about the recipient copy. Use [Patrick](p2-p32-patrick-opinions-readback.md) to test whether the corrected report and subsequent actual decision can be identified. Keep the propositions about receipt, reliance and relief separately reviewable.
