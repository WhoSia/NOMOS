# P2-P31 — Same-information review sheet for a person predicate

Use one row per proposition, actor and decision. Write the person predicate and the receiving purpose in ordinary language before opening the later packet. Preserve the literal documentary basis and a page or exhibit. A later argument can be compared as an argument while the paired-decision field stays unobserved.

| Field required from both reviewers | Positive evidence | Direct falsifier or insufficient item |
|---|---|---|
| Proposition changed | The named authority corrects the same factual claim or adopts a corrected version with that claim resolved | Acknowledging a dispute without granting it, or changing an unrelated field |
| Use changed | The later reasoning identifies a traceable record version or the specific basis on which the same conclusion now rests | A new label for a derivative ending at the withdrawn source, or no basis available |
| Relevance was narrowed | A stated rule or clear reason restricts what the acknowledged fact supports in the current task | A different fact being corrected upstream, or a mere yes/no disposition |
| Counterevidence was interpreted | The reason accepts the action and attributes it to a motive, constrained situation or concealment, with the source of that inference separately coded | An unsupported inference about the decisionmaker's personal motives, or a refusal to acknowledge the event itself |
| Decision was replaced | Different operative act IDs, correct authority and question, and a supported chronology | Later explanation of the earlier act, notice from another actor, or unresolved ordering |

Start with the actual Patrick and Fikre incomplete packets. Add a constructed matched pair with a genuinely independent later reason and an equivalent pair in which the later citation descends from the corrected source. Supply all documents to both reviewers and preserve disagreement on adequacy. Test held-out actual positive cases separately from constructed controls. The test target is whether the combined workflow changes which support can be cited or which missing observation would change a judgment. This sheet describes a comparison to be run, and no inter-rater outcome has been measured.
